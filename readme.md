# Jefferson Girardi — Portfólio

Meu portfólio pessoal e repositório de estudos em desenvolvimento web.

## Estrutura

```
├── index.html              ← Portfólio pessoal (página inicial)
├── css/                    ← Estilos do portfólio
├── assets/                 ← Imagens e recursos
│
├── projects/               ← Projetos em destaque
│   ├── redes-sociais/      ← Simulador de iPhone com redes sociais
│   ├── fourpay-website/    ← Site institucional FourPay Solutions
│   ├── site-android/       ← História do mascote do Android
│   └── cordel/             ← Cordel Moderno (parallax)
│
├── studies/                ← Estudos e exercícios
│   ├── html-css/           ← Exercícios de HTML & CSS (ex011-ex025)
│   ├── faculdade-js/       ← Exercícios de JavaScript da faculdade
│   └── aulas-uninter/      ← Aulas da Uninter (AULA 1, 3, 4, 5)
│
├── misc/                   ← Projetos secundários
│   ├── fourpay-admin/      ← Dashboard administrativo FourPay
│   ├── chat-franqueado/    ← Portal do franqueado
│   ├── db-dynamo/          ← Estudos DynamoDB Local
│   └── galeria-videos/     ← Galeria de vídeos
│
└── university/             ← Trabalhos acadêmicos Uninter
    ├── portfolio/          ← Portfólio pessoal (versão Uninter)
    ├── projeto-tecnologia/ ← Blog de tecnologia
    └── projetoex/          ← Projeto Extensionista (Flask)
```
